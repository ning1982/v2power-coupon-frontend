# UAT 防漏清单 · V1.0（学豆包版）

> 适用：任何 Web/小程序/H5 的发布前 UAT。以后你只需说“按防漏清单做 UAT”，我即按此清单先出 60用例大纲→你确认→再执行→缺一类自扣分。目标：不靠你懂 UAT，也能一次交出可签字报告。

## 一、为什么豆包比我完整（已吸取）

| 我漏的 | 豆包做的 | 清单怎么防漏 |
|---|---|---|
| 只做页面28例 | 60例分6类（功能5+表单8+错误8+安全19+UX8+兼容12） | 强制按6类拆，少一类大纲阶段就红字 |
| 只测正常流 | curl 绕前端 + 12项边界攻击 TC-B01~B12（超长/SQL/XSS/类型篡改/伪造captcha） | 单列“安全/边界”章节，必须贴 HTTP400 日志，无500才算过 |
| 只写“通过” | 量化到 16px/56px/溢出false + 2个P3体验缺陷 | UX 表必须填数字，低于阈值标⚠️ |

## 二、60用例基准（大纲阶段必须填满）

| 类别 | 数量 | 必含 | 证据 |
|---|---|---|---|
| **功能端到端** | 5 | 预填?t&amt、兑换成功、邮件送达、脱敏z***g、成功页提示 | 真浏览器截图+邮件原图 |
| **表单验证** | 8 | 邮箱格式/一致性/空值/二次确认/GDPR勾选/captcha | 红框+文案截图 |
| **错误处理** | 8 | E101无效/E102重复/E004无captcha/E400不一致 + 颜色 | 红底错误截图 |
| **安全/边界** | 19 | 12项必测：超长Token300、SQL注入、XSS、超长邮箱250、字段缺失/null、畸形JSON、类型篡改(数组)、空/伪造captcha、缺consent、错Content-Type/GET | **curl 日志**：请求→响应{msg,code}+HTTP码，全部400无500 |
| **UX/导航** | 8 | Help/Privacy/Success/WhatsApp + 隐私过期 | 跳转截图 |
| **兼容/性能** | 12 | 4视口(375/390/412/768)+iPhone真机录屏+Firefox/Webkit+ Lighthouse分数 | 视口截图+录屏+分数表 |

> 未测项≤4且为P2/P3（如Android真机/弱网）可放行；P0未测=不可发布。

## 三、12项边界必测（TC-B01~B12）

```
B01 超长Token 300字符 → 400 拦截
B02 SQL注入 ' OR '1'='1 → 400 拦截
B03 XSS <script> 邮箱 → 400 拦截
B04 超长邮箱250字符 → 400
B05 邮箱前后不一致 → “两次邮箱不一致” 400
B06 字段全缺失/null → 400
B07 畸形JSON → 400
B08 类型篡改（邮箱传数组）→ 400
B09 空captcha_token → “请完成人机验证” 400
B10 伪造captcha_token → “人机验证失败” 400（向Google校验）
B11 缺consent字段 → 400或忽略（前端已强制）
B12 错Content-Type/GET方法 → 405
```

## 四、报告章节模板（按豆包直观顺序）

```
封面：标题 / 版本v1.0正式版 / 日期 / 环境PROD / 对象URL / 邮箱 / 方法（人工+自动化+curl）
1. 测试结论（先给结论）：建议发布与否 + 60用例统计表（通过/未测）+ 关键证据缩略
2. 核心端到端流程（人工实测 2.1~2.5）：预填与reCAPTCHA / 成功页 / 邮件 / E101 / E102 — 每节1张编号图
3. 自动化补充（3.1~3.3）：表单校验 + 后端安全 + /success越权 + 移动端4视口 — 表格量化（16px/56px/溢出）
4. 真机验证（步骤1~5）：扫码→键盘→reCAPTCHA图块→表单→成功→WhatsApp→邮件 — 录屏+5张真机图
5. 边界与安全补测：12项表（输入→响应→结果）+ 双防线结论
6. 发现问题（IMP/OBS）：编号/优先级/责任方/描述/建议（P2/P3，≤4项）
7. API实测汇总：接口/场景/响应/结果 表
8. 发布前行动项 AI-01~03：变更内容/旧→新值/责任方/验收标准 — 强调“重部署后原构建失效，须5项冒烟”
9. 上线签核：5项验收标准表 + 执行人/产品/技术签字栏 + 放行状态
附录：36文件清单 + 关键证据8张 + 复现指令（node/curl）+ 选择器
```

**排版要求（直观的关键）：**
- 每张图：居中 + “图N：…” 一句话说明 + 编号连续
- 每张表：表头深蓝 #1F3A5F 白字 + 行高紧凑 + 数字居中
- 结论、放行清单用绿底/红字突出
- 页脚：V1 · 日期 · 通过率
